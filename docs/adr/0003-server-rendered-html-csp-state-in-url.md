# 0003 — Server-rendered HTML, strict CSP, page state in the query string

- **Status:** Accepted
- **Date:** 2026-09-11
- **Deciders:** maintainer

## Context

Дашборд читає локальні дані й показує таблиці, числа й кілька графіків. Спокуса взяти клієнтський фреймворк зростає з кожним інтерактивним елементом: перемикач періоду, фільтр за проєктом, підказки на графіках. Водночас репозиторій тримає рівно одну залежність і не має збірки фронтенду.

## Decision drivers

- `AGENTS.md`: залежність одна, збірки фронтенду й UI-фреймворка немає.
- `idea-brief.md` §5: зовнішні шрифти й ресурси поза обсягом.
- CSP у `layout()` і прив'язка до `127.0.0.1` це межа, яку не послаблюємо без рішення людини.
- Стан сторінки має бути посиланням: його копіюють, зберігають у закладки й передають.

## Decision outcome

**Chosen:** сторінки рендеряться на сервері як HTML, без фреймворка і без збірки.

- Скрипти лише статичні файли з `public/`, під CSP, і лише там, де без них фіча не працює: підказки на графіках, перемикач теми.
- Inline-скриптів і inline-обробників подій немає.
- Стан сторінки живе в параметрах запиту: період, ліміт, фільтр за проєктом, сортування, пошук. Кожен стан це адреса, яку можна відкрити наново.
- Зовнішніх шрифтів, CDN і мережевих запитів зі сторінки немає.

## Consequences

**Positive**
- Сторінка працює без JavaScript у базовому вигляді; скрипт лише додає зручність.
- Будь-який стан відтворюється з адреси, тому баг описується посиланням.
- Нуль збірки: правка в `views/` або `public/` видно після перезавантаження.

**Negative**
- Складна клієнтська взаємодія коштує дорого: кожна дія це новий запит і повний рендер.
- Частина патернів сучасного UI недоступна без порушення межі.

**Neutral**
- Тема це найраніший зі скриптів `public/`: він має відпрацювати до першого кадру, і це окреме рішення (див. [[0004-theme-same-tokens-system-first]]).
