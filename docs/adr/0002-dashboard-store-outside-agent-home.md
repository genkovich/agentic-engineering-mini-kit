# 0002 — Dashboard's own data lives outside the agent home, in a single JSON file

- **Status:** Accepted
- **Date:** 2026-09-11
- **Deciders:** maintainer

## Context

Дашборд має власні дані, яких немає в журналах: людські назви сесій, згодом теги, нотатки й закладки. Їх треба десь тримати, а єдина тека з сесіями під рукою це домашня тека агента, писати в яку заборонено. Бази даних у репозиторії немає і не буде.

Рішення закриває D5 з роадмапу.

## Decision drivers

- `AGENTS.md` §Межі: джерело сесій лише читаємо, записів у `CLAUDE_HOME` рівно нуль.
- `AGENTS.md`: бази даних немає, залежність рівно одна.
- Тести й `demo` мусять мати змогу підмінити сховище тимчасовою текою, не чіпаючи домашню теку розробника.
- Обсяг даних малий: сотні записів, читаються цілком на кожен запит.

## Decision outcome

**Chosen:** власні дані живуть у `AGENT_OPS_HOME`, типово `~/.agent-ops`, в одному JSON-файлі, і пишуться лише через `lib/store.js`.

- Читання: файла немає або він нечитабельний — це порожнє сховище, а не помилка.
- Запис атомарний: тимчасовий файл поруч і `rename`, щоб перерваний запис не лишив півфайла.
- Ключ це id сесії; значення розширюється новими полями без міграції формату.
- Тести й `demo` задають `AGENT_OPS_HOME` самі.

## Consequences

**Positive**
- Межа «не пишемо в джерело» лишається абсолютною і не має винятків.
- Одна точка запису, тому інваріанти перевіряються в одному модулі.
- Видалення теки сховища повертає дашборд у чистий стан без втрати сесій.

**Negative**
- Один файл означає повне перечитування й перезапис на кожну зміну; для десятків тисяч записів це стане тісно.
- Дані не переносяться між машинами самі.

**Neutral**
- Перехід на кілька файлів або інший формат можливий пізніше й лишається в межах `lib/store.js`.
