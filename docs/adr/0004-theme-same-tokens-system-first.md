# 0004 — One set of tokens, dark theme by override, system first

- **Status:** Accepted
- **Date:** 2026-09-11
- **Deciders:** maintainer

## Context

Дашборд відкривають поруч із терміналом, і він має виглядати доречно в обох темах. Найпростіший шлях, окремий темний стиль, означає дві палітри, які розходяться з першою ж правкою. Другий ризик це мерехтіння: сторінка рендериться на сервері, тому без окремого кроку світла тема встигає блимнути перед темною.

## Decision drivers

- `design-system.md`: токени живуть у `public/style.css`, стиль рівно один.
- `AGENTS.md`: збірки фронтенду немає, тому препроцесора чи генерації палітри теж немає.
- Вибір теми це перевага людини, а не стан сторінки, тому в адресі йому не місце (див. [[0003-server-rendered-html-csp-state-in-url]]).

## Decision outcome

**Chosen:** один набір токенів, темна тема це перевизначення тих самих імен.

- Світла палітра визначена на `:root`; темна перевизначає лише значення токенів, не додаючи нових імен.
- Типово тема йде за системою; явний вибір людини перемагає систему в обидва боки.
- Вибір зберігається в `localStorage` цього браузера і застосовується до першого кадру окремим скриптом із `public/`, підключеним найпершим.
- Контраст пар перевіряється валідатором палітри; жоден колір не має єдиного визначення всередині темного блока.

## Consequences

**Positive**
- Компонент отримує темну тему безкоштовно: він використовує імена, а не кольори.
- Немає мерехтіння при завантаженні, бо тема застосована до рендера тіла.
- Одна палітра означає одне місце правки.

**Negative**
- Темна тема не може розійтися зі світлою там, де це було б доречно: нюанси тіней і насиченості обмежені спільними іменами.
- Потрібен маленький скрипт до першого кадру, тобто сторінка не повністю без JavaScript.

**Neutral**
- Вибір зберігається лише в цьому браузері й не синхронізується.
