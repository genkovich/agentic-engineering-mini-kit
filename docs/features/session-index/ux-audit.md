# UI/UX-аудит — session-index

> Незалежний аудит першого екрана, виконаний окремим агентом на живій сторінці з фікстур.
> Аудит відображає стан до появи темної теми, другого графіка й спільного `columnChart()`;
> пункти про графік перевірити повторно після цих змін. Рішення, що з цього робимо, ухвалює
> власник; прийняті пункти стають критеріями в `spec.md` або задачами в `tasks/`.

## 1. Що працює

- Ієрархія «числа → моделі → графік → проєкти → сесії» відповідає brief §7 і читається за секунду; сторінка спокійна, один акцент, без карток із тінями.
- Стан цілком в URL: період, ліміт, пошук, фільтр живуть у посиланнях, форма GET, `?limit=1` дає «All 6». Це чесна реалізація «поділитись відфільтрованим виглядом».
- Кольори проєктів консистентні між графіком, легендою, таблицями й підказкою; підказка графіка має чесний no-script fallback через `<title>`.
- Порожні стани розрізняють «сесій немає» і «нічого не збіглось із “zzz”», є посилання скинути фільтр.
- Rename-сторінка прямо каже, де зберігається назва і що в теку агента не пише. Це правильна мікрокопія для межі приватності.

## 2. Проблеми юзабіліті (за спаданням)

1. **Rename недоступний з клавіатури і невидимий мишею.** `.rename-link { visibility: hidden }` прибирає посилання з tab-порядку, тому правило `.rename-link:focus-visible` ніколи не спрацьовує; мишею його видно лише на hover рядка. Фікс: завжди показувати іконку `pencil` з `opacity:.35`, повна на `tr:hover, tr:focus-within`; текст «Rename» лишити в `aria-label`. S.
2. **Stat strip змішує «за весь час» і «за період».** Контейнер підписаний «Totals for the last 30 days», але перша плитка «sessions in total» всечасна, поруч «active in 30 days» з тією ж іконкою і тим самим числом. Три плитки токенів мають одну іконку, а cache візуально найбільше число на сторінці, хоч найменш корисне. Фікс: один підпис періоду над смужкою, прибрати «of 30» і «in 30 days» з плиток, всечасну кількість перенести в заголовок «Recent sessions», cache-токени в `title`. S.
3. **Перемикач періоду стоїть у панелі графіка, а керує всією сторінкою.** `?days=3650` мовчки падає на 30, хоча канон каже: набраний руками параметр падає на дефолт із `Note`, як `?limit`. Фікс: періоди в рядок під `h1` поруч зі scope-текстом; `Note` для невалідного `days`. S.
4. **Колонка «Session» не окупає ширину.** UUID обрізаний, не клікабельний. Turns і Output tokens у рядку сесії дублюють Projects з малими числами; «Size» це проксі. «Modified» тут і «Last activity» у Projects для того самого mtime. Фікс: id у `title` name-cell (пошук по id лишається), місце віддати назві; «Modified» → «Last activity»; Output tokens і Size другорядним рядком або в `title`. S.
5. **Три способи фільтра за проєктом, один напівживий.** `<select>` застосовується лише після «Apply», рядок Projects і легенда фільтрують кліком. У scoped-вигляді таблиця Projects каже «Projects 3» з глобальними числами під scoped-статистикою. Фікс: select прибрати, фільтр лишити за таблицею й легендою; у scoped-режимі приглушити неактивні рядки. S.
6. **Графік майже порожній і без опор.** Вісь Y лише max і 0, тікі кожні 7 днів від довільної дати, вихідних не видно. На вузькому екрані SVG масштабується цілком (D8). Фікс: тік на понеділках, ледь помітні смуги вихідних, цілі лінії сітки при `max ≤ 5`, маркер «сьогодні»; більший текст SVG під `@media`. M.
7. **Rename: окрема сторінка й дивна копія.** Label «Own name» не ідіома; placeholder дорівнює journal title, тож для безіменної сесії поле показує «Untitled session» як підказку. Після Save лише крапка без тексту. Фікс: label «Name», placeholder «e.g. Postgres boot», крапку доповнити `title` «named by you». Форма в рядку через `<details>` без JS можлива, але це M.
8. **Мікрокопія і терміни.** «Show newest 10/25/50/100» читається як команда; заголовок сесій має три граматики; «assistant turns» і «cache tokens» без пояснення; зелена крапка джерела статична, але читається як health. `th` без `scope="col"`, select без видимого label. S.

## 3. Нові ідеї для першого екрана

1. **Відносний час** («2 h ago», «yesterday») у клітинці, абсолютний у `title`; `now` уже інʼєктується в `listSessions()`. S, крок 1.
2. **Команда продовження** `claude --resume <id>` у `<code>` замість колонки id. S; роадмап кладе це в крок 2, але це найдешевша річ, яку варто витягнути в крок 1.
3. **Сортування таблиці сесій** через `?sort=turns|tokens|time` посиланнями в `th`. S–M, крок 1 (за вартістю це крок 3).
4. **Групування сесій за днем** («Today», «Yesterday», «23 Aug») рядками-розділювачами; підсвітка сьогоднішніх. S, крок 1.
5. **Тривалість сесії** (перший і останній `timestamp`, поле вже дозволене) замість Size. S, крок 1; на сторінці сесії у кроці 2 стане обовʼязковою.
6. **Sparkline у рядку Projects** з `dash.days.byProject`. Уже зроблено після аудиту.
7. **Перемикач метрики графіка** `?metric=sessions|turns|output` тим самим `segmented`. S–M, крок 3, але дешево.
8. **Осмислений бейдж джерела**: зелений, коли теку прочитано і є сесії; бурштин при `unreadableCount>0`; сірий, коли порожньо; поруч «last activity 3 weeks ago». S, крок 1.
9. **Оцінка вартості**: не ставити плейсхолдер, поки D4 відкрите; лише `title` з розкладом токенів. Крок 3.
10. **Клавіша «/» у пошук** потребує скрипта; канон дозволяє скрипт лише там, де без нього не працює, тож або не робити, або визнати винятком. S, крок 4.

## 4. Топ-5 рекомендацій

1. Зробити Rename видимим і фокусованим: іконка завжди, `tr:focus-within`, без `visibility:hidden`.
2. Перебудувати stat strip: один підпис періоду, без «of 30», всечасне число окремо, cache у `title`.
3. Таблиця сесій: id у `title`, «Modified» → «Last activity», відносний час, команда `--resume`.
4. Перемикач періоду на рівень сторінки, `Note` для невалідного `days`, select замінити на фільтр через Projects і легенду.
5. Графік: тіки по понеділках, смуги вихідних, цілі лінії сітки, окремий розмір тексту для вузького екрана (закриває D8).
